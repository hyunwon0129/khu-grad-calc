# 배포하기 — 설치 없이 링크로 접속

이 앱은 서버 프로그램이 필요 없는 **정적 웹사이트**입니다. 빌드된 폴더(`dist`)를 무료 호스팅에 올리면
누구나 `https://…` 링크로 바로 씁니다. 사정표 분석은 방문자 브라우저 안에서 이루어지므로 서버 비용·보안 부담이 없습니다.

## 방법 A. Netlify Drop — 5분, 코딩 도구 불필요 (공모전 제출용 추천)

1. https://app.netlify.com/drop 접속 → 무료 가입(구글·GitHub·이메일)
   - 가입하지 않고 올리면 사이트가 1시간 뒤 삭제됩니다. 반드시 로그인한 상태에서 올리세요.
2. `khu-grad-calc-site.zip`을 풀어서 나온 **폴더째로** 화면의 점선 상자에 끌어다 놓기
   (폴더 안에 `index.html`이 바로 보여야 합니다)
3. 몇 초 뒤 `https://임의이름.netlify.app` 주소가 생깁니다
4. **Site configuration → Change site name**에서 주소를 바꿀 수 있습니다 (예: `khu-grad-calc.netlify.app`)
5. 수정본을 올릴 때: 사이트의 **Deploys** 탭 하단 상자에 새 폴더를 다시 끌어다 놓기 (주소 유지)

## 방법 B. GitHub Pages — 수정할 때마다 자동 배포 (공모전 이후 운영용)

1. GitHub 가입 → 새 저장소(예: `khu-grad-calc`, Public) 생성
2. 프로젝트 폴더 전체를 저장소에 올리기 (`node_modules`, `dist` 제외. `.gitignore`가 처리)
3. 저장소 **Settings → Pages → Source: GitHub Actions**
4. 이후 main 브랜치에 올릴 때마다 `.github/workflows/deploy.yml`이 테스트 → 빌드 → 배포
5. 주소: `https://<GitHub아이디>.github.io/khu-grad-calc/`

claude.ai 설정에서 GitHub를 연결하면 2~5단계는 Claude가 대신할 수 있습니다.

## 방법 C. Vercel

https://vercel.com → Add New Project → GitHub 저장소 선택 → Deploy. (방법 B의 저장소가 있어야 함)

## 배포 전 점검

- [ ] 시작 화면 → "가상 사정표로 먼저 체험해 보기" → 결과 화면까지 동작
- [ ] 휴대폰에서 주소 열어 보기
- [ ] 화면에 실제 개인 사정표 정보가 남아 있지 않음 (시연용은 가상 사정표만)
- [ ] 하단 "비공식 서비스·최종 판단은 학교 학사 시스템" 문구 확인
- [ ] 학교 로고·휘장은 사용 허가 확인 전 넣지 않음
